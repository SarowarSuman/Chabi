# 🔑 Chabi

A sign-in form that cuts a key. Type your password and a tiny hammer strikes one notch into the key for every character. Hit **Sign in** and the key slides into the lock. Only the right password lines up the pins and opens it.

> **Just a fun project.** This is not a real login system. The password is checked in the browser and is visible in the source code, so never use it for anything real.

**Live:**

## Try it

Any email, and password `sumanerkey`.

## Run locally

Open `index.html` in a browser. No build step, no dependencies.

## Built with

Plain HTML, CSS and JavaScript. The animation is SVG. No libraries (only the Inter font from Google Fonts).
